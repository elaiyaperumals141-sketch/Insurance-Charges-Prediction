# 🏥 Insurance Charges Prediction Using Machine Learning

An end-to-end Machine Learning project that predicts medical insurance charges based on customer information using **Linear Regression**. The project includes data preprocessing, exploratory data analysis, model training, evaluation, and an interactive web application built with Streamlit.

## 🌐 Live Application

**Try the application here:**

[🚀 Insurance Charges Prediction – Live Demo](https://insurance-charges-prediction-2008.streamlit.app/)

## 📌 Project Overview

The main objective of this project is to develop a Machine Learning model that estimates individual medical insurance charges based on various personal and lifestyle-related factors.

The model is trained using the Insurance dataset and deployed as an interactive web application using Streamlit.

Users can enter customer details and receive predicted insurance charges instantly.

## 📊 Dataset Information

The project uses the Insurance dataset (`insurance.csv`).

### Input Features

| Feature | Description |
|---|---|
| age | Age of the individual |
| sex | Gender of the individual |
| bmi | Body Mass Index |
| children | Number of children |
| smoker | Smoking status |
| region | Residential region |

### Target Variable

- **charges** – Individual medical insurance charges.

## ⚙️ Machine Learning Workflow

1. **Data Collection** – Load the insurance dataset using Pandas.
2. **Exploratory Data Analysis (EDA)** – Analyze dataset structure, statistical information, missing values, and distributions.
3. **Data Cleaning** – Remove duplicate records and handle missing values.
4. **Data Preprocessing** – Perform one-hot encoding for categorical features.
5. **Feature Scaling** – Apply StandardScaler to numerical features.
6. **Train-Test Split** – Split the dataset into 80% training and 20% testing data.
7. **Model Training** – Train a Linear Regression model.
8. **Model Prediction** – Predict insurance charges using test data.
9. **Model Evaluation** – Evaluate the model using regression metrics.
10. **Model Deployment** – Save the trained model and deploy it using Streamlit.

## 🤖 Machine Learning Algorithm

**Linear Regression**

Linear Regression is a supervised Machine Learning algorithm used to predict continuous numerical values by identifying relationships between input features and the target variable.

The model uses six input features to estimate medical insurance charges.

## 📈 Model Evaluation Metrics

The model performance is evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R-squared (R²)

These metrics help measure prediction errors and understand how well the model fits the data.

## 🚀 Run the Project Locally

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/Insurance-Charges-Prediction.git
```

### 2. Navigate to the Project Directory

```bash
cd Insurance-Charges-Prediction
```

### 3. Install Dependencies

```bash

```

### 4. Run the Streamlit Application

